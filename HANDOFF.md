# Trellis engineering handoff — deprecated

**Status: DEPRECATED as an active session authority on July 21, 2026.**

This compatibility stub preserves the well-known path while the retired manual
engineering-loop machinery and its references remain in repository history. It
contains no current objective, baseline, sequencing decision, or acceptance
claim. Do not infer work from an older revision of this file.

For a new engineering task:

1. Read [`AGENTS.md`](AGENTS.md), the canonical agent entrypoint and permanent
   repository rules.
2. Follow the collaborator's live task. A clear live instruction outranks the
   committed record.
3. Read [`docs/GLOSSARY.md`](docs/GLOSSARY.md) and the smallest useful depth of
   [`docs/ORIENTATION.md`](docs/ORIENTATION.md).
4. Retrieve the task's governing source records before deciding or claiming
   what they establish.

Historical session material remains available in
[`docs/archive/TRELLIS_ROADMAP_DEPRECATED.md`](docs/archive/TRELLIS_ROADMAP_DEPRECATED.md),
[`docs/archive/ROADMAP_HISTORY.md`](docs/archive/ROADMAP_HISTORY.md), and Git
history. The engineering-loop controller and its records remain preserved under
`tools/engineering-loop/` and `docs/product/engineering-loop/`; deprecating this
manual prompt does not claim that controller migration was adopted.
