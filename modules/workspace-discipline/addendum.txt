WORKSPACE DISCIPLINE PROTOCOL

Tool Capture
- Capture every tool result into the workspace before returning from the tool wrapper.
- Return only a stub with a segment identifier, byte count, and a bounded preview.
- Store full tool result content only in workspace segments.
- Do not return full tool results into root context.
- Do not rely on model discipline for capture.
- Enforce capture and return discipline in tooling; use prompt instructions only as reinforcement.

Workspace State
- Keep the plan, self-notes, and evidence in the workspace.
- Carry working state in the workspace, not in scrollback.
- Represent workspace state as version-tagged JSON-serializable data.
- Do not store live object graphs, callables, or library-specific runtime objects.
- Do not keep full result content in root context.

Read and Reuse
- Fetch each external result once, then reuse the stored segment.
- Read full content explicitly from segments or by querying over stored segments when needed.
- Re-read stored material deliberately instead of re-calling external tools.
- Seed later goal tasks from prior workspace snapshots when available.
- Do not restart dependent work from scratch when a seeded snapshot can carry it forward.

Atomic Updates and Bounds
- Build new workspace state first, then rebind it in one atomic transition.
- Treat torn in-place updates as untrusted and repairable.
- Validate workspace bounds through configured hard limits.
- Raise a readable error when a workspace write exceeds budget.
- Do not silently truncate stored workspace state.
- Keep workspace operations out of the database tool-call counter.

Evidence Standing
- Use the verified ingest path to make workspace content citable.
- Do not treat workspace content by itself as provenance-standing.
- Emit a protocol violation when an answer is produced with no database tool calls.

Code-Mediated Text
- Load text into queryable structured REPL state.
- Index first, then pull only the bounded material needed for the current step.
- Use queries to compute locations and extract slices.
- Do not paste whole loaded text into scrollback for model inspection.
- Never make the model count when the environment can compute the location.
- Never make the model copy existing bytes through attention.

Edits by Code
- Re-query handles each turn and treat computed addresses as transient.
- Find edit locations by content query, then splice by code at the computed address.
- Follow the cycle load, query, splice, write, then discard transient frames.
- Use line or row granularity for surgical writes.
- Use block or AST granularity for understanding and provenance.
- Make edits only through code-mediated operations.
- Never persist a positional handle across mutations.
- Never emit a full-document rewrite of existing text.
- Do not keep a long-lived in-memory mirror that can silently drift.

Write Verification
- Capture a digest when loading text and verify it before write-back.
- On digest mismatch, refuse write-back loudly.
- Never silently overwrite on mismatch.
