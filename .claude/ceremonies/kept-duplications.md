# Kept duplications — human rulings the ceremony honors

Repetition that a human has ruled **ceremonious** lives here. The dedupe
ceremony reads this file before it decides anything and leaves these claims
whole.

The list grows in one direction. Every ruling added makes the ceremony more
conservative than it was, which is the safe direction for a loop that runs
unattended: a claim, once protected, stays protected until a human says
otherwise.

**Adding an entry.** Name the claim, name every location, state which anchor
makes it ceremonious, and sign it with the date and who ruled. An entry without
an anchor is a claim waiting to be rehomed.
