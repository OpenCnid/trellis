Trunk · T0 · what Trellis is, in one sentence

Trellis is a personalized composable expert system whose expertise is the user's data — not strictly a coding tool, not strictly a RAG system — built as OpenCnid's Recursive Language Model runtime: the user's context, memory, knowledge, and capabilities live as queryable engine state with enforced provenance, the model reaches all of it only through code, and because the expertise is the user's data the user is the domain authority — Trellis composes its experts, judges, and protocols per question from primitives against that data and never overrules the user about the user's own domain.
